# Habit Tracker

Habit Tracker — это небольшой backend-проект для отслеживания привычек, отметок выполнения и базовой статистики прогресса.

Проект создаётся как учебный pet-project на Go с постепенным усложнением: сначала in-memory хранение и бизнес-логика, затем HTTP API, база данных и дополнительные функции.

## Цель проекта

Сделать простой и понятный сервис, который позволяет:
- создавать привычки;
- редактировать их;
- отмечать выполнение по дням;
- смотреть streak и статистику;
- постепенно расширять проект по мере обучения.

## MVP

Минимальная версия проекта включает:
- сущность Habit;
- хранение в памяти;
- CRUD для привычек;
- отметку выполнения за день;
- расчёт текущей серии выполнения (streak);
- тесты на основную логику.

## Функциональность

- Создание привычки.

- Отметка выполнения привычки по дате.
- Просмотр статистики по привычке.

### Планируется

- Фильтрация и сортировка.

## Сущности

### Habit
- ID.
- Название.
- Описание.
- Дата создания.
- Дата обновления.
- Активность / архив.

### HabitLog
- ID.
- Habit ID.
- Дата.
- Статус выполнения.
- Комментарий.

### HabitStats
- Текущий streak.
- Лучший streak.
- Количество выполненных дней.
- Количество пропущенных дней.
- Процент выполнения.

## Правила проекта

- У одной привычки не может быть двух отметок на одну дату.
- Архивную привычку нельзя отмечать как выполненную.
- Бизнес-логика живёт в сервисе, а хранилище отвечает только за данные.
- Статистика рассчитывается отдельно от репозитория.
